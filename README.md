## 🔐 Security Principles Applied

| Principle | Description |
|-----------|-------------|
| **Least Privilege** | Users receive only the minimum permissions required |
| **Zero Trust** | Every access request must be verified continuously |
| **Just-In-Time Access** | Privileged access is temporary and controlled using PIM |
| **Defense in Depth** | Multiple security controls are layered together |
| **Identity-Centric Security** | Identity becomes the primary security perimeter |
